# Support

Choose the route that matches your request. This project does not provide a
private support email or a guaranteed response time.

## Security

Report suspected vulnerabilities through GitHub's
[private vulnerability-reporting form](https://github.com/po4yka/fuji-cli/security/advisories/new).
Do not disclose them in a public issue. See the [security policy](SECURITY.md)
for scope and privacy requirements.

## Installation and USB Access

Start with the [installation guide](docs/users/installation.md), including its
Linux permissions, macOS camera-process, and Windows driver guidance. If the
problem remains and is reproducible, open a
[software bug](https://github.com/po4yka/fuji-cli/issues/new?template=bug_report.yml).

## Camera Compatibility

Read the [support matrix and evidence policy](docs/users/support.md) before
testing. Submit a physical-device result with the
[compatibility form](https://github.com/po4yka/fuji-cli/issues/new?template=compatibility_report.yml).
Do not rerun a state-changing command solely to complete a report.

## Software Bugs and Feature Requests

- Report reproducible behavior with the
  [bug form](https://github.com/po4yka/fuji-cli/issues/new?template=bug_report.yml).
- Propose an outcome or workflow with the
  [feature-request form](https://github.com/po4yka/fuji-cli/issues/new?template=feature_request.yml).

Before posting publicly, remove camera serial numbers, backup artifacts, private
RAF/JPEG files, custom-setting names, secrets, and unreviewed `-vvv` output.
